📚 DSA Concepts Used (Implemented in C)

📦
Array
Patient record store. O(1) access, O(n) search.
🔗
Doubly Linked List
Audit log history. O(1) insert at tail, O(n) traversal.
📚
Stack (LIFO)
Emergency patients. Last-in first-out. O(1) push/pop.
🚶
Circular Queue (FIFO)
Regular waiting list. O(1) enqueue/dequeue.
⛰️
Min-Heap
Priority treatment queue. O(log n) insert/extract-min.
🌳
BST
Patient ID index. O(log n) average search/insert.
#️⃣
Hash Table
Name lookup. O(1) average. Separate chaining, djb2 hash.
🕸️
Graph (Adj. List)
Ward adjacency. BFS and DFS traversal.
📐
Merge Sort
Sort by name. Stable, O(n log n).
⚡
Quick Sort
Sort by age. Avg O(n log n), in-place.
🏔️
Heap Sort
Sort by priority. O(n log n), in-place.
🔢
Insertion Sort
Sort by ID. Best-case O(n) for nearly sorted.
🫧
Bubble Sort
Sort by bill (demo). O(n²) worst case.
🔭
Linear Search
Name/condition/ward search. O(n).
🎯
Binary Search
ID search on sorted array. O(log n).
